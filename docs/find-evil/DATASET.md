- Evidence type: Disk image

- Source: provided by the submitting team
- Acquisition notes: document tool, date, and source system here
- SHA-256: generated by `hash_evidence`

## Reproducibility

Judges should set:

```bash
export ORPHEUS_FIND_EVIL_IMAGE="/absolute/path/to/case-image.dd"
export ORPHEUS_FIND_EVIL_CASE_ID="find-evil-case-001"
```

Run:

```bash
bun run find-evil:validate
bun run find-evil:demo
```

If the first pass reports partition-offset failures, use the offset shown in
`partitions.txt` and rerun with `--offset`.
